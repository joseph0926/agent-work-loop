# Git 규칙

이 저장소의 커밋과 반영 방식이다. git-suggest 스킬과 에이전트는 이 파일을 우선한다.

## 흐름

- 브랜치를 만들지 않는다. `main`에서 커밋하고 `origin/main`에 바로 push한다.
- PR을 만들지 않는다. 그래서 브랜치명과 PR 본문은 추천하지 않는다.

## 커밋 메시지

- 제목: 변경을 요약한 영어 명령형 한 줄, 72자 이내. 마침표를 붙이지 않는다.
- 본문: 한국어. 제목 다음에 빈 줄을 두고, 바뀐 것과 이유를 짧은 목록으로 쓴다. 한 가지만 바뀌어 제목으로 충분하면 본문을 생략한다.
- AI 도구나 모델 사용을 드러내는 문구와 trailer(`Co-Authored-By`로 AI를 표기하는 것 포함)를 넣지 않는다.
